# 新旧 iOS UI 对照 · 2026-09-27

基准：同一台 iPhone 18 Pro / iOS 27 模拟器，旧 React Native 应用连接本仓库 Metro（8087），原生应用使用独立 Debug bundle ID。两者只读取现有生产资讯，没有更改后端或线上订阅。

## 已实测发现并修正

| 页面 / 区域 | 原生初版问题 | 本轮调整 |
| --- | --- | --- |
| 发现页 | 导航标题、搜索框、频道条、通用大标题重复占空间 | 保留单层频道条；移除没有旧版依据的通用页头及搜索框 |
| 微博 | 每条新闻被渲染为多行粗体卡片，热度挤到下面 | 恢复单行标题、左侧排名圆点、右侧热度、44pt 最小点击高度 |
| 知乎 | 通用卡片未体现热榜结构 | 左侧排名、标题与热度、右侧小图 |
| 少数派 / B站 / 36氪 | 封面都被缩成右侧正方形；部分元数据缺失 | 左侧横向封面；恢复少数派点赞评论、B站作者/播放/点赞 |
| 小宇宙 | 右侧封面加下方大播放按钮，行高与旧版不符 | 左封面、中间标题/作者/时长、右侧独立播放按钮 |
| 豆瓣 / TIOBE / 历史 | 三种内容都套用同一新闻卡片 | 竖版海报、独立五列表格、年份与摘要分别呈现 |
| Arena | 通用大标题；日期、会话数、说明入口遗漏 | 恢复专属说明、日期/会话数/模型数、方法说明链接；Models/Labs 保留 |
| 订阅 | 添加了无必要的宣传标题，品牌图标被系统图标取代 | 移除宣传块，复用旧版频道 SVG/PNG，保留原生排序/开关 |
| 播放器 | 在整个 TabView 外插入底部区域 | iOS 26.1+ 使用系统 Tab Bar accessory，旧系统采用标准 material |

原生 Tab Bar、分段控件、表单、圆角和系统字体是有意保留的原生设计，并不要求逐像素复制 React Native。

## 验证范围与未完成项

- 旧版实际截图：微博、知乎、少数派、Arena、订阅、我的；不是只看源码推断。
- 原生 UI 回归覆盖 12 个频道切换与截图、深色 Arena、订阅表单、登录同意门槛及播放/暂停。
- 微博另有布局断言：第一项位于频道条后（y < 180pt），正常字号行高不超过 55pt。
- 最终模拟器回归通过：4 个单元测试、3 个 UI 测试；订阅开关右对齐断言亦通过。
- 网络图片首次加载时有占位状态，少数派另经等待加载后确认封面能够显示。截图中的即时资讯可能因刷新时间不同而变化。
- **仍未完成全量一致性验收**：Arena 厂商远程 SVG logo、RSS 的旧版紧凑样式、豆瓣星级图形、History 时间轴连线，以及大字号/横屏/旧 iOS 的逐页截图仍需继续核对。当前只修复并验证上述主要结构问题。
- 账号写入、跨端配置恢复、真机背景播放及旧版 MMKV 迁移不在这轮视觉验证内。

所有改动在 `feature/ios-native-rebuild` 的 `ios-native/` 内；未修改旧 React Native UI，未生成发布包。
