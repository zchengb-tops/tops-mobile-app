# 新旧 iOS UI 对照 · 2026-09-27

基准：同一台 iPhone 18 Pro / iOS 27 模拟器，旧 React Native 应用连接本仓库 Metro（8087），原生应用使用独立 Debug bundle ID。两者只读取现有生产资讯，没有更改后端或线上订阅。

## 已实测发现并修正

| 页面 / 区域 | 原生初版问题 | 本轮调整 |

- 底部导航复用旧 `NavBar.js` 的三枚 Ionicons，固定为左图标、右文字；三个入口保持独立导航栈。

- 模拟器已通过订阅／我的／发现切换、RSS 表单、登录同意门槛回归；增加系统 Tab Bar 不得重复显示的检查。
- 深色底栏及迷你播放器使用较厚的系统深色玻璃底色，阻隔列表文字干扰；未选中导航恢复旧版白色图标／文字，播放器状态文字沿用旧版 `#AAAAAA`，选中态继续使用深灰。

- 模拟器录影逐帧确认连续位移；导航回归增加三个入口的选中状态检查并通过。深灰配色、图标、左右布局及底部间距保持不变。

## 开放式布局与捏合密度 · 2026-10-04

按最新反馈，覆盖上一版 grouped 阅读卡片设计：

- 发现页去掉包住整张热榜的大圆角面板及文章外层卡片，改用通栏语义背景、20pt 内容边距和细分隔线；文章／视频的封面本身保留小圆角。订阅改为原生 plain List，保留开关、排序和 RSS 左滑操作。
- 页面及滚动背景延伸到玻璃底栏和 home indicator 后方，移除顶部栏、底栏及播放器的不透明 tint 和安全区底板；保留原始导航图标、左右布局、深灰选中板及平移动画。「减少透明度」或增强对比度时继续使用实体可读底板。
- 「我的」不再使用通用 grouped Form；改为渐变阅读空间页头、真实频道图标／订阅数量、带图标的阅读偏好、同步及关于信息。邮箱登录、字号、外观、自动同步、上传、确认恢复、版本／更新、外链、退出及法律文档均保留。登录／RSS 弹层不受主页面底部空间影响，法律文档保留原生返回导航。
- 资讯密度独立于字号，默认「标准」，另有「紧凑」「舒展」：一次双指捏合切换一档，实时提示当前档位，松手保存到本机；到边界不再继续缩放。文章／视频在缩略图与展开封面间切换，其他频道调整行距／摘要／封面大小，表格与 Arena 不删除指标，股票只调整绘图区高度。字号及原始文字家族保持不变。
- 使用 SwiftUI 原生 MagnifyGesture，保留单指纵向阅读、水平分页、下拉刷新和阅读器导航。频道菜单、设置选择器和 VoiceOver 自定义动作也能调整密度；减少动态效果时不动画重排。
- 屏幕边界回归发现 page-style TabView 的内部滚动面仍停在 939pt（屏幕底为 956pt）。最终频道分页改用系统 ScrollView 的 paging / scrollPosition，而非补一个固定 17pt 高度或位移；各频道纵向滚动视图保持常驻，频道栏、菜单和横滑共用同一选中状态。尺寸来自当前布局，不绑定机型。原生分页 API 参考 [Apple · Beyond scroll views](https://developer.apple.com/videos/play/wwdc2023/10159/)。
- 模拟器双指测试使用无遮挡的资讯项作为目标：对整张 Feed 模拟合拢时，首触点可能落在浮动播放器上，不能将这种跨控件手势当作列表收到的完整双指手势。最终实现没有保留临时 UIKit 手势桥接或诊断日志。
- 继续使用实测底栏高度加 16pt 的滚动末项避让，未加入独立白色占位板；未修改后端、旧 RN 工程或线上订阅，未提交或生成发布包。
- iPhone 18 Pro Max / iOS 27 分轮覆盖 5 个单元测试、16 个 UI 测试。最终分页调整后重新验证了全部频道的实际可见性、图文捏合／重启密度恢复、浅／深色横滑与位置保持、热榜捏合／设置切换、12 频道末项（额外含 Arena Labs 与股票说明）、Web 返回后位置及三主页面的屏幕边界；最新一轮 5 个相关 UI 测试和 5 个单元测试全部通过。此前的设置／订阅／法律文档末项、大字号、登录同意门槛和播放回归也通过。自动化检查等待实际可操作的页面，而非只确认后台存在相应元素；启动时显式恢复频道位置，避免选中项与内容不一致。
- 实际截图确认展开封面与紧凑缩略图均不再有外层阅读面板，图片颜色透过底部玻璃并延伸至屏幕底边。回归没有发送验证码或上传线上订阅；iOS 17–26 运行时、真机音频及旧版数据迁移仍未验收。

## 登录与微博排版精修 · 2026-10-04

## Logo 动态登录背景 · 2026-10-04
